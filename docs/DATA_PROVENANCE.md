# 자료 출처와 처리

## 출처

| 자료 | 공급자 | 내용 | 비고 |
|---|---|---|---|
| SPY·QQQ 일별 시세 | Yahoo Finance (yfinance) | 최근 2년 종가, 조정종가, 배당 | 공식 지원 서비스가 아님. 개인 연구·교육 용도. 지연·수정 가능 |
| 옵션 체인 | Yahoo Finance (yfinance) | 만기·행사가별 호가, 거래량, 미결제약정, 공급자 IV | 상장 옵션은 미국형. 참고용 |
| 금리 | FRED DGS3MO, DGS1, DGS2 | 미국 국채 고정만기 수익률(%) | API 키가 있으면 공식 API, 없으면 공개 CSV |
| 가상 자료 | backend/fixtures/synthetic_demo.json | 시드 고정 상관 GBM으로 만든 520거래일 경로 | 실제 시세가 아님. backend/scripts/make_fixture.py로 재생성 |

## 표기

| 표기 | 의미 |
|---|---|
| REAL MARKET DATA | 이번 실행에서 공급자로부터 받은 값 |
| CACHED REAL SNAPSHOT | 수집 실패로 이전에 받은 실제 스냅샷을 재사용 |
| MANUAL SCENARIO | 사용자가 직접 입력한 값 |
| SYNTHETIC DEMO | 가상 자료 |
| MODEL ESTIMATE | 자료로부터 계산한 추정값(실현변동성, 상관계수, 이론가, Greeks 등) |

## 처리 규칙

- 기준일은 두 자산이 모두 거래된 가장 최근 날짜다. 서로 다른 날짜의 값을 한 스냅샷에 섞지 않는다. 자산별 최신 거래일이 다르면 품질 경고를 남긴다.
- 옵션 평가의 현물가는 미조정 종가, 수익률·변동성·상관계수 계산은 조정종가를 쓴다.
- 금리는 % 단위를 소수로 바꾼다(4.5% → 0.045). 관측일과 수집 시각을 따로 저장한다.
- 기준일이 4일 넘게 지났으면 stale 경고를 표시한다.
- 미국 시장 시각은 America/New_York, 저장 시각은 UTC ISO 8601이다. 정규장 개장 여부는 시간으로만 판정하며 휴장일은 반영하지 않는다.
- 옵션 호가는 `매도호가 ≥ 매수호가 ≥ 0`일 때만 중간값을 계산한다. 무차익 범위를 벗어나면 내재변동성을 계산하지 않고 `IV unavailable`로 둔다.
- 금리 수집에 실패하면 수동 가정값(4%)을 `MANUAL SCENARIO`로 표시하고 경고를 남긴다.
- 스냅샷은 로컬 SQLite(`backend/data/app.db`)에 원자료와 함께 저장한다. 화면에서 JSON으로 내보낼 수 있다. 외부로 전송하는 자료는 없다.
- API 키는 `.env`에서 읽으며 화면, 로그, 저장소에 남기지 않는다.

## 시계열 자료의 전제

- 일별 종가는 하루 한 번의 관측이다. 장중 변동과 호가 스프레드는 담기지 않는다.
- 과거 변동성과 상관계수는 계산 구간에 따라 달라지며 미래 값을 보장하지 않는다.
- 재헤지 시뮬레이션의 변동성은 시작일 이전 자료만으로 계산한다.
