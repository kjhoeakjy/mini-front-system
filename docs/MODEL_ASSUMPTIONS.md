# 모형 가정과 한계

## 계산 정의

| 항목 | 정의 |
|---|---|
| 옵션 | 배당 포함 BSM, 유럽형, 현금결제, 승수 100, T = 달력일수/365 |
| 금리 | 국채 고정만기 수익률(3개월·1년·2년)을 연속복리 평탄 금리로 근사. 만기 사이는 선형 보간 |
| 변동성 | 조정종가 일별 로그수익률의 표준편차 × √252 (기본 252거래일). 내재변동성의 대용치 |
| 상관계수 | 최근 252거래일 로그수익률의 Pearson 상관계수. 위험중립 상관계수의 대용치 |
| 배당 | 최근 12개월 배당 합계 ÷ 현물가를 연속 배당수익률로 근사 |
| 노트 기초자산 | 위험중립 2자산 GBM, 평탄 변동성, 고정 상관계수, 연 252스텝 |
| 낙인 관측 | 시뮬레이션 일별 종가. 평가 시점 포함 |
| 관측일 | 기준일 + 6·12·18·24개월. 주말이면 수정후영업일 규칙으로 조정. 거래소 휴장일 미반영 |
| 쿠폰 | 계약상 연수(0.5, 1.0, 1.5, 2.0) × 연 쿠폰율. 단리, 상환 시 일괄 지급 |
| 할인 | exp(−r × 실제 일수/365) |
| Monte Carlo | 기본 20,000경로, 대조 변수(antithetic) 사용. 표준오차는 경로쌍 평균 기준 |
| 노트 Greeks | 공통 난수 중앙차분. 현물 ±0.5%, 변동성 ±0.5%p, 금리 ±50bp, 상관계수 ±0.10 |
| 충격 분석 | 계약의 기준가·행사가는 고정하고 평가용 시장 입력만 이동 |

## 한계

1. 교육용이며 거래 권고, 실제 상품 가격, 특정 회사 내부 시스템의 재현이 아니다.
2. 시장 자료는 공급자에 따라 지연·누락·수정될 수 있으며 이용 약관이 적용된다.
3. 상장 SPY·QQQ 옵션은 미국형이다. 유럽형 BSM 이론가와 일치하지 않는다.
4. 국채 고정만기 수익률은 할인곡선이 아니다. 평탄 금리는 단순화다.
5. 실현변동성은 내재변동성과 다르다. 노트 평가에 필요한 위험중립 정보를 반영하지 못한다.
6. 변동성·상관계수·배당을 일정하다고 가정한다. 스마일, 국면 전환, 점프는 반영하지 않는다.
7. 일별 낙인 관측은 연속 관측과 다르며 가격 차이가 생길 수 있다.
8. 상환·손실 경로의 비율은 위험중립 모형 아래의 빈도이며 실제 발생 확률이 아니다.
9. 델타 중립은 작은 가격 변화에 대한 일차 위험만 줄인다. 감마, 베가, 갭, 유동성, 거래 비용 위험은 남는다.
10. 다음은 제공하지 않는다: 발행 후 경과한 노트의 재평가, 노트 Theta, 거래상대방 신용위험, 조달 비용, 변동성 곡면, 세금, 환율, 실제 주문과 한도 관리.
11. 기계학습 기반 가격 근사는 포함하지 않는다.

## 노트 평가 범위

발행 시점 신규 계약만 평가한다. 잔존만기는 항상 2년으로 보고, 현물가가 기준가와 다른 경우(충격 분석, 수동 입력)에는 기준가 대비 비율만 반영한다. 발행 후 경과한 상품을 평가하려면 지난 관측 결과와 낙인 여부를 저장해야 한다.
