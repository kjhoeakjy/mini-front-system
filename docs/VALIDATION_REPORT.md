## 1. BSM

| 검증 | 방법 | 결과 |
|---|---|---|
| 기준값 | S=100, K=100, T=1, r=5%, q=0, σ=20% | 콜 10.450584, 풋 5.573526 (알려진 값과 일치) |
| 풋콜 패리티 | S 3종 × T 3종 × (r, q) 3종 × σ 2종 = 54개 조합 | 오차 < 1e-8 |
| 무차익 범위 | 0 ≤ 콜 ≤ S·e^(−qT), 0 ≤ 풋 ≤ K·e^(−rT) | 통과 |
| Greeks 부호 | 콜 Delta ≥ 0, 풋 Delta ≤ 0, Gamma ≥ 0, Vega ≥ 0 | 통과 |
| 해석식과 중앙차분 | Delta·Gamma·Vega·Rho·Theta. 간격 dS=1e-3, dσ=dr=dT=1e-5. 음의 금리 포함 | 허용오차 1e-4~1e-6 내 일치 |
| 단위 | Vega(+1%p), Rho(+100bp)를 실제 재계산 차이와 비교 | 1~2% 내 일치 (1차 근사) |
| 부호·승수 | 매수/매도 전환 시 전 항목 부호 반전, 계약 Delta = 주당 × 100 | 통과 |
| 예외 | 만기 도래(T ≤ 0), σ = 0, 음의 금리, 극단 행사가, 잘못된 입력 | 통과 |
| 내재변동성 | σ 4종 × 콜/풋 왕복 역산 | 오차 < 1e-7 |
| 내재변동성 실패 처리 | 무차익 하한 이하·상한 이상 가격 | 숫자 대신 상태 코드 반환 |

## 2. 노트 지급 규칙 (난수 미사용)

지정한 경로를 지급 함수에 직접 넣어 계약상 기대값과 비교했다.

| 사례 | 경로 조건 | 기대 지급액 | 결과 |
|---|---|---:|---|
| A | 6개월 W=0.97 | $1,050 | 일치 |
| B | 6개월 미충족, 12개월 W=0.92 | $1,100 | 일치 |
| C | 조기상환 3회 미충족, 만기 W=0.83 | $1,200 | 일치 |
| D | 낙인 없음, 만기 W=0.75 | $1,200 | 일치 |
| E | 최저 W=0.55(낙인), 만기 W=0.70 | $700 | 일치 |
| F | 낙인 후 반등, 18개월 W=0.86 | $1,150 | 일치 |
| G | 낙인, 만기 W=0.30 | $300 | 일치 |

추가 확인: 배리어와 같은 값은 충족으로 처리(W=0.95 조기상환, W=0.60 낙인), worst-of는 낮은 자산 기준, 조기상환 이후의 급락은 무시, 경로 하나씩 읽는 구현과 배열 구현이 무작위 400경로에서 지급액·상환 회차·범주 모두 일치.

## 3. Monte Carlo 엔진

| 검증 | 결과 |
|---|---|
| 재현성 | 같은 입력·경로 수·시드에서 동일 결과. 시드가 다르면 결과가 다름 |
| 범주 합 | 조기상환 3개 + 만기 3개 범주의 비율 합 = 1 |
| 묶음 크기 | 계산 묶음 크기를 바꿔도 결과 동일 (경로 단위 난수 생성) |
| 엔진 점검 | 1자산 유럽형 콜 20만 경로: 10.4122 (표준오차 0.0232), BSM 10.4506과 3 표준오차 내 |
| 상관 | 난수 표본 상관과 표본 경로 일별 수익률 상관이 설정값과 일치 (오차 0.01~0.02 내) |
| 기준가 고정 | 현물가만 내리면 가치 하락, 기준가도 함께 내리면 가치 불변 |
| 낙인 관측 | 평가 시점 비율이 낙인 수준 이하면 낙인 경험 비율 100% |
| 단조성 | 쿠폰을 올리면 가치 상승, 낙인 배리어를 내리면 가치 상승·손실 비율 감소 |
| 일정 | 수정후영업일 규칙, 관측일과 연수 계산 |

수렴 (SPY 500/QQQ 400, σ 18%/24%, q 1.2%/0.6%, r 4%, ρ 0.85, 시드 42):

| 경로 수 | 이론가 | 표준오차 |
|---:|---:|---:|
| 1,000 | 1,005.03 | 4.597 |
| 5,000 | 1,006.79 | 1.994 |
| 20,000 | 1,003.46 | 1.032 |
| 100,000 | 1,002.46 | 0.466 |

표준오차는 대체로 1/√n 비율로 줄어든다. 20,000경로에서 시드 5개의 이론가는 1,001.02~1,004.09로 표준오차 범위와 부합한다. 100,000경로 1회 평가는 약 1.5초다.

## 4. 노트 Greeks

- 투자자 기준 Delta 합 > 0, Vega 합 < 0. Theta는 숫자를 만들지 않고 N/A.
- Vega(+1%p), Rho(+100bp)가 실제 재계산 차이와 15% 내 일치.
- 알려진 한계: 배리어에서 지급액이 불연속이어서 Delta·Gamma 추정의 잡음이 크다. 현물 충격 폭 0.25%·0.5%·1%의 추정값을 화면에 함께 표시하고 차이가 15%를 넘으면 경고한다. Delta가 작은 자산(상대적으로 변동성이 낮은 쪽)은 부호가 바뀔 수 있다.

## 5. 장부·헤지·스트레스

| 검증 | 결과 |
|---|---|
| 옵션 행 | 평가금액 = 주당가 × 100 × 부호 있는 수량, Delta는 해당 기초자산에만 집계 |
| 현물 행 | 1주 = Delta 1, Gamma·Vega 0 |
| 합계 | 기초자산별 합 = 행 합, 달러 Delta = Delta × 현물가 |
| Theta | 노트가 있으면 부분 집계로 표시 |
| 헤지 방향 | 주당 Delta 0.60인 콜 1계약 매도 → −60주 노출 → 60주 매수 |
| 반올림 | 정수 주식 거래 후 잔여 Delta와 비용 재계산 |
| 시나리오 손익 | 충격 후 평가금액 − 기준 평가금액과 일치, 포지션별 기여의 합과 일치 |
| 계약 고정 | 충격 적용 후에도 행사가·기준가 불변 |
| 재헤지 시뮬레이션 | 헤지 없음의 최종 손익 = 프리미엄 − 만기 지급액 (금리 0, 비용 0). 주기가 짧을수록 거래 횟수·비용 증가. 만기에 주식 청산 |
